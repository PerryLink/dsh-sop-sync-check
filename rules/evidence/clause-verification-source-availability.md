# 条文核查报告 —— 汽车行业工具手册类插件：**来源不可取得的原因与影响**

**适用插件**：`dsh-ppap-check`（引 AIAG PPAP 手册）、`dsh-sop-sync-check`（引 IATF 16949 与五大工具手册）、
`dsh-fmea-table-check`（引 FMEA 标准）

- **核查日期**：2026-10-07
- **核查性质**：⚠️ **本报告不是"查到错误"，而是把"为什么查不到"写清楚** ——
  这类来源**不是公开文本**，无法像国家标准那样逐字核对。
- **结论**：**这两个插件的诚实披露经审查确认准确**（第一节），
  且本轮**查明并记录了不可取得的制度性原因**（第二节），
  **并指出日后若要改变这一状态，唯一可行的路径是使用方自备正版文件**（第四节）。

## 一、✅ 审查确认：两个插件的披露是**准确的**

### 1.1 `dsh-ppap-check` 头部（逐字）

> 「⚠️⚠️ 本规则库的诚实说明：**excerpt 一律不是引文。**……
> 其规范载体是汽车行业的 **AIAG《生产件批准程序（PPAP）手册》**……
> **核查未取得该手册的逐字条文**，因此本规则库**不伪造任何"原文"**：
> 每条规则的 excerpt 都写明"该条文本次未取得"……
> **取得条文后必须做两件事**：把 excerpt 换成真正的逐字摘录，把 kind 升为 direct。
> 在那之前，本插件的命中信息只应被读作"这个要素没提交 / 版本没填 / 等级没写明"，
> 而**不是**"PPAP 不合格"。」

### 1.2 `dsh-sop-sync-check` 头部（逐字）

> 「⚠️⚠️ 本规则库的诚实说明：**excerpt 一律不是引文。**……
> 其规范载体是 IATF 16949 体系与汽车行业的五大工具手册（APQP／PFMEA／控制计划）。
> **核查未取得这些文件的逐字条文**……
> 在那之前，本插件的命中信息只应被读作"版本对不上 / 引用缺失 / 参数栏没填"，
> 而**不是**"体系不符合 IATF 16949"。」

### 1.3 逐项核对结果

| 检查项 | `dsh-ppap-check` | `dsh-sop-sync-check` |
|---|---|---|
| `excerpt` 是否伪造引文 | ✅ **无** —— 全部为"本次未取得"形态 | ✅ **无** |
| `clause` 是否断言条号 | ✅ **无** —— 全为"关于……的条款（**本次未取得条号**）" | ✅ **无** |
| `number` 是否断言版本 | ✅ 写作「AIAG PPAP（**现行版次与条号本次未核实**）」 | ✅ 同类表述 |
| `kind` 是否保守 | ✅ 一律 `derived-from-principle`（封顶 warn）或 `institutional-configuration`（封顶 info） | ✅ 同 |
| 是否写明"取得后须升级" | ✅ **写明了两步（换 excerpt、升 kind）** | ✅ **同** |
| 是否划清能力边界 | ✅ "绝不判定 PPAP 是否可批准、提交等级是否恰当" | ✅ "绝不判定工艺参数是否合理、控制计划是否覆盖全部失效模式" |

⇒ **两个插件在"取不到原文"的情况下做到了本项目要求的一切**：
**不伪造引文、不断言条号、不冒充版本、封顶严重级、并写明补救路径。**
**本轮无任何更正项。**

## 二、⚠️ 本轮查明：**这类来源不是公开文本，查不到是制度性的**

本项目此前的做法是"从政府网站或标准公开平台取得全文"。**对这两类来源，该路径不通**：

| 来源 | 发布主体 | 为什么取不到 |
|---|---|---|
| **《生产件批准程序（PPAP）手册》** | **AIAG**（Automotive Industry Action Group，美国汽车工业行动集团） | **商业出版物**，经 AIAG 及其授权渠道**销售**发行；AIAG 另有**最终用户许可协议**（EULA）约束其电子文档的使用 |
| **IATF 16949** | **IATF**（International Automotive Task Force） | **版权标准**，须经 IATF 及其监督办公室／授权机构**购买**；IATF 并发布过关于**使用未经授权版本**的声明 |
| **五大工具手册（APQP／PFMEA／控制计划／MSA／SPC）** | **AIAG**（部分与 VDA 等联合） | 同 PPAP，**商业出版物** |

⇒ **这三个来源既非法律法规、也非公开国家标准**，故：
1. **不能从政府网站取得**；
2. **不能从国家标准全文公开系统取得**；
3. **取得正版需要付费**，而**本项目不具备采购授权**。

⚠️ **本次尝试的经过（如实记录）**：检索到 IATF 监督办公室（IAOB）与 AIAG 的若干公开 PDF 链接，
但**均无法抓取**（`application/pdf` 不被支持，或跨域重定向失败）。
⇒ **"查不到"不是因为我没找，而是因为公开渠道只有版权声明与目录，没有正文。**

## 三、这对本插件意味着什么（如实标注）

1. **这两个插件的 `basis` 永远无法达到"逐字核对"状态** —— 除非使用方自备正版文件；
2. **这不是插件的缺陷**：它们核对的是**台账自身的齐备与自洽**
   （要素是否提交、版本是否一致、序号是否重复、占位符是否残留），
   **这类核对在原理上不依赖条文原文**；
3. ⇒ **它们的 `kind` 长期保持 `derived-from-principle` 是正确且稳定的**，
   **不应**因为"一直没取得原文"而被误认为"待办事项未完成"。
   **这一点值得在 README 中写明**，以免日后被当成技术债。
